## Codebase Patterns
- Game logic is pure functions in `server/src/gameLogic.ts`; server state/physics in `server/src/index.ts`
- `evaluateTurnEnd` mutates state (calls `assignGroupsIfNeeded`) — capture pre-mutation state if needed
- Tests use vitest, run with `cd server && npm test`; typecheck with `npx tsc --noEmit` from root
- `TurnResult` interface and `evaluateTurnEnd` are the core of all turn-end rule logic
- Browser testing: server on port 8080 (WebSocket), client on port 5173 (Vite); use `dev-browser` CLI for UI verification
- `dev-browser` screenshots save to `~/.dev-browser/tmp/`; use `page.snapshotForAI()` for snapshot-based assertions
- React 18 container key: `__reactContainer$xxxx` (not `__reactFiber`); find WebSocket via walkFiber checking `memoizedState.current instanceof WebSocket`
- Server's shoot power is divided by 100; send `power: 100` via direct WS for full-power shot (client normalizes 0-1)
