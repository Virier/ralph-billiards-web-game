## Codebase Patterns
- Monorepo: /client (React+Vite) and /server (Node+ws), each has own package.json and tsconfig.json
- Client typecheck: `cd client && npm run typecheck` (tsc --noEmit with bundler moduleResolution)
- Server typecheck: `cd server && npm run typecheck` (tsc --noEmit with NodeNext module)
- Server dev runner: `tsx watch src/index.ts` (no ts-node)
- Root package.json scripts: dev:client, dev:server, typecheck
- Server message protocol: JSON over WebSocket; client sends `join_room` (roomCode: "" to create, code to join)
- Server sends: `room_created`, `room_joined`, `error`, `start_game` (with GameState + playerIndex), `opponent_disconnected`
- Game state types (Ball, GameState) exported from server/src/index.ts for future sharing
- Table dimensions: 1400×700, ballRadius=14, rackX=TABLE_WIDTH*0.75 (foot spot), cueBall at x=TABLE_WIDTH*0.25
- Use `import { randomUUID } from 'crypto'` for Node.js UUID generation (not global crypto)
